모공 1등 앰플

상세페이지 · 배너

01 / OVERVIEW

Project Overview

생성형 AI로 가상의 모공 케어 앰플과 제품 연출 이미지를 제작하고, 상세페이지와 광고 배너로 확장한 개인 프로젝트입니다. 모공과 피부결 관리에 관심 있는 20~30대 소비자를 고려해 제품 특징과 성분, 사용감을 순서대로 소개했습니다.

02 / PLANNING

Planning & Goal

Problem

다양한 제품 특징과 성분을 정리하면서 상세페이지와 배너 각각의 목적에 맞게 메시지를 전달해야 했습니다.

Goal

상세페이지에서는 제품 정보를 이해하기 쉽게 전달하고, 배너에서는 핵심 장점과 프로모션을 빠르게 인지하도록 구성했습니다.

Strategy

피부 고민에서 제품 솔루션·성분·사용 방법으로 이어지는 정보 흐름을 설계하고, 배너에는 ‘3중 모공 케어’ 메시지와 제품 비주얼을 집중 배치했습니다.

03 / DESIGN POINT

Design Point

01. Layout

피부 고민 → 제품 특징 → 성분 → 사용 방법 순서로 내용을 배치하고, 배너는 제품과 핵심 문구가 먼저 보이도록 구성했습니다.

02. Color & Type

브라운·베이지 계열로 따뜻하고 차분한 분위기를 표현하고, Pretendard의 크기와 굵기를 달리해 정보의 우선순위를 구분했습니다.

03. Visual

AI로 제작한 제품·연출 이미지를 Photoshop으로 보정·합성하고, 성분 아이콘과 인포그래픽으로 정보를 시각화했습니다.

04 / FINAL DESIGN

Final Design



05 / RESULT

Result & Reflection

가상의 제품을 상세페이지와 배너로 확장하면서 콘텐츠별 정보의 양과 강조점을 조절했습니다. 서로 다른 형식에서도 컬러와 비주얼 콘셉트를 일관되게 유지하는 방법을 익혔습니다.

02 / PLANNING

Planning & Goal

Problem

다양한 메뉴와 브랜드 콘텐츠를 사용자가 메인 화면에서 쉽게 확인할 수 있도록 구성할 필요가 있었습니다.

Goal

사용자가 필요한 메뉴와 정보를 쉽게 찾을 수 있도록 화면을 구성하고, 브랜드의 일관된 이미지를 유지하는 것을 목표로 하였습니다.

Strategy

주요 메뉴를 메인 화면에 카드 형태로 배치하고, 콘텐츠별 영역을 구분하여 정보의 접근성을 높이고자 하였습니다.

03 / DESIGN POINT

Design Point

01. Layout

상단에는 시즌 프로모션을 크게 배치하고, 그 아래에는 사용자가 자주 찾는 주요 메뉴를 카드 형태로 정렬하였습니다. 하단에는 브랜드 소식과 매장 찾기 등의 콘텐츠를 구분하여 필요한 정보를 쉽게 확인할 수 있도록 구성하였습니다.

02. Color & Type

이디야커피 로고의 블루 컬러를 포인트 색상으로 활용하여 브랜드의 통일성을 유지하였습니다. 나눔고딕(NanumGothic) 서체를 사용하고, 제목과 본문의 크기 및 굵기에 차이를 두어 정보의 가독성을 높였습니다.

03. UI Design

주요 메뉴를 이미지와 텍스트가 결합된 카드형 UI로 구성하여 각 메뉴의 내용을 직관적으로 전달하였습니다. 또한 콘텐츠별 바로가기 버튼을 배치하여 사용자가 원하는 정보를 쉽게 탐색할 수 있도록 디자인하였습니다.

04 / FINAL DESIGN

Final Design

05 / RESULT

Result & Reflection

브랜드의 기존 컬러를 유지하면서 주요 메뉴와 콘텐츠를 메인 화면에 재배치한 프로젝트입니다. 사용자가 필요한 정보를 쉽게 확인할 수 있도록 콘텐츠의 우선순위와 배치를 고민했으며, 브랜드의 시각적 일관성과 사용자 편의성을 함께 고려하는 디자인 과정을 경험했습니다.

03. UI Design

Final Design

Planning & Goal

Problem

Goal

Strategy

Final Design
