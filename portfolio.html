모공 1등 앰플

상세페이지 · 배너

01 / OVERVIEW

Project Overview

생성형 AI로 가상의 모공 케어 앰플과 제품 연출 이미지를 제작하고, 상세페이지와 광고 배너로 확장한 개인 프로젝트입니다. 모공과 피부결 관리에 관심 있는 20~30대 소비자를 고려해 제품 특징과 성분, 사용감을 순서대로 소개했습니다.

02 / PLANNING

Planning & Goal

Problem

다양한 제품 특징과 성분을 정리하면서 상세페이지와 배너 각각의 목적에 맞게 메시지를 전달해야 했습니다.

Goal

상세페이지에서는 제품 정보를 이해하기 쉽게 전달하고, 배너에서는 핵심 장점과 프로모션을 빠르게 인지하도록 구성했습니다.

Strategy

피부 고민에서 제품 솔루션·성분·사용 방법으로 이어지는 정보 흐름을 설계하고, 배너에는 ‘3중 모공 케어’ 메시지와 제품 비주얼을 집중 배치했습니다.

03 / DESIGN POINT

Design Point

01. Layout

피부 고민 → 제품 특징 → 성분 → 사용 방법 순서로 내용을 배치하고, 배너는 제품과 핵심 문구가 먼저 보이도록 구성했습니다.

02. Color & Type

브라운·베이지 계열로 따뜻하고 차분한 분위기를 표현하고, Pretendard의 크기와 굵기를 달리해 정보의 우선순위를 구분했습니다.

03. Visual

AI로 제작한 제품·연출 이미지를 Photoshop으로 보정·합성하고, 성분 아이콘과 인포그래픽으로 정보를 시각화했습니다.

04 / FINAL DESIGN

Final Design



05 / RESULT

Result & Reflection

가상의 제품을 상세페이지와 배너로 확장하면서 콘텐츠별 정보의 양과 강조점을 조절했습니다. 서로 다른 형식에서도 컬러와 비주얼 콘셉트를 일관되게 유지하는 방법을 익혔습니다.

빛 실험용 원형 물통

영상 콘텐츠 기획 · 촬영 · 편집

01 / OVERVIEW

Project Overview

빛의 성질을 쉽고 흥미롭게 이해할 수 있도록 제작한 교육 영상입니다.
공기와 물의 경계에서 빛이 나아가는 모습을 관찰할 수 있으며, 영상을 따라 하면서 실험 도구의 사용법을 익히고 직접 실험을 진행할 수 있도록 제작하였습니다.

Category
Video Production
Role
기획 · 촬영 · 편집 · 썸네일 제작
Tools
Premiere Pro · Photoshop
Period
2025.11
CONTRIBUTION
100%
02 / PLANNING

Planning & Goal

Problem

실험 도구의 사용법과 빛의 진행 과정을 글과 이미지만으로 이해하기 어려움

Goal

빛의 성질을 쉽게 이해하고 직접 실험할 수 있도록 안내

Strategy

질문과 간단한 애니메이션을 활용해 시청자의 호기심을 유도하고, 자연스럽게 실험 과정에 집중하도록 구성

03 / TARGET & CONCEPT

Target & Concept

Target

과학 실험에 관심 있는 학생 및 교육자

Key Message

직접 관찰하고 따라 하며 이해하는 빛의 성질

Visual Concept

실험 과정과 관찰 결과를 중심으로 한 직관적인 교육 영상

04 / DESIGN POINT

Design Point

01. Layout

실험 순서에 따라 자연스럽게 이어지는 화면 구성

02. Color & Type

실험 장면을 방해하지 않는 간결한 자막과 그래픽

03. Visual

빛의 진행 방향과 실험 결과가 잘 드러나는 다양한 촬영 구도

05 / FINAL DESIGN

Final Design

06 / RESULT

Result & Reflection

레이저 빛의 굴절 현상을 선명하게 촬영하는 데 어려움이 있었지만, 이를 효과적으로 보여주기 위해 촬영 구도와 표현 방식을 고민했습니다. 또한 시청자가 실험 과정을 쉽게 이해하고 따라 할 수 있도록 영상의 전개 순서와 편집 구성에 신경 썼습니다. 이번 작업을 통해 교육 영상에서는 시각적 전달력뿐 아니라 정보의 흐름과 이해하기 쉬운 구성이 중요하다는 점을 배웠습니다.

01 / OVERVIEW

Project Overview

이디야커피 웹사이트의 주요 메뉴와 콘텐츠를 사용자가 편리하게 확인할 수 있도록 메인 페이지를 재구성한 웹 리디자인 프로젝트입니다. 브랜드의 기존 이미지를 유지하면서 주요 메뉴를 메인 화면에 배치하고, 정보의 접근성과 가독성을 고려하여 디자인했습니다.

Category
Web / UI Design
Role
디자인
Tools
Photoshop
Period
2023
CONTRIBUTION
100%
02 / PLANNING

Planning & Goal

Problem

다양한 메뉴와 브랜드 콘텐츠를 사용자가 메인 화면에서 쉽게 확인할 수 있도록 구성할 필요가 있음

Goal

사용자가 필요한 메뉴와 정보를 쉽게 찾을 수 있도록 화면을 구성, 브랜드의 일관된 이미지를 유지하는 것을 목표

Strategy

주요 메뉴를 메인 화면에 카드 형태로 배치, 콘텐츠별 영역을 구분하여 정보의 접근성을 높이고자 했음

03 / DESIGN POINT

Design Point

01. Layout

상단에는 시즌 프로모션을 크게 배치, 그 아래에 사용자가 자주 찾는 주요 메뉴를 카드 형태로 정렬 하단에는 브랜드 소식과 매장 찾기 등의 콘텐츠를 구분하여 필요한 정보를 쉽게 확인할 수 있도록 구성

02. Color & Type

이디야커피 로고의 블루 컬러를 포인트 색상으로 활용하여 브랜드의 통일성을 유지했습니다. 나눔고딕(NanumGothic) 서체를 사용, 제목과 본문의 크기 및 굵기에 차이를 두어 정보의 가독성을 고려

03. UI Design

주요 메뉴를 이미지와 텍스트가 결합된 카드형 UI로 구성하여 각 메뉴의 내용을 직관적으로 전달, 콘텐츠별 바로가기 버튼을 배치하여 사용자가 원하는 정보를 쉽게 탐색할 수 있도록 디자인

04 / FINAL DESIGN

Final Design

05 / RESULT

Result & Reflection

브랜드의 기존 컬러를 유지하면서 주요 메뉴와 콘텐츠를 메인 화면에 재배치한 프로젝트입니다. 사용자가 필요한 정보를 쉽게 확인할 수 있도록 콘텐츠의 우선순위와 배치를 고민했으며, 브랜드의 시각적 일관성과 사용자 편의성을 함께 고려하는 디자인 과정을 경험했습니다.

포르쉐의 브랜드 이미지와 주요 차량 모델을 효과적으로 전달하기 위해 진행한 웹사이트 리디자인 프로젝트입니다. 메인 페이지에서는 주력 모델을 강조하고 주요 콘텐츠로 쉽게 이동할 수 있도록 구성했으며, 서브 페이지에서는 다양한 차량을 한눈에 살펴보고 비교할 수 있도록 레이아웃을 정리했습니다.

02 / PLANNING

Planning & Goal

Problem

다양한 차량 모델과 브랜드 콘텐츠를 사용자가 쉽게 탐색, 원하는 차량의 정보를 효율적으로 확인할 수 있는 화면 구성이 필요가 있음

Goal

포르쉐의 고급스럽고 현대적인 브랜드 이미지를 유지하면서 주요 차량에 대한 접근성과 모델 탐색의 편의성을 높이는 것을 목표

Strategy

메인 페이지에는 주력 차량을 중심으로 콘텐츠를 배치하고, 사이드 바로가기 메뉴를 구성, 서브 페이지에는 차량을 그리드 형태로 정렬하고 분류 메뉴를 배치하여 모델별 정보를 쉽게 확인할 수 있도록 디자인

03 / DESIGN POINT

Design Point

01. Layout

메인 페이지는 대형 차량 이미지와 주요 콘텐츠를 중심으로 구성, 화면 좌측에 바로가기 메뉴를 배치하여 원하는 영역으로 쉽게 이동할 수 있도록 배치, 서브 페이지는 4단 그리드를 활용해 차량을 정렬, 모델별 정보를 비교하기 편리하도록 구성

02. Color & Type

포르쉐 로고의 컬러를 참고하여 레드, 블랙, 화이트를 주요 색상으로 활용, Roboto와 맑은 고딕(Malgun Gothic) 서체를 사용하여 간결하고 현대적인 분위기를 유지, 차량 이미지와 주요 정보가 돋보이도록 디자인

03. UI Design

메인 페이지에는 사이드 바로가기 메뉴와 콘텐츠별 이동 영역을 배치하고, 서브 페이지에는 차량 분류 메뉴와 카드형 UI를 적용, 차량 이미지와 모델명을 일정한 형식으로 정리하여 사용자가 여러 모델을 직관적으로 탐색할 수 있도록 구성

04 / FINAL DESIGN

Final Design

05 / RESULT

Result & Reflection

브랜드의 시각적 특징을 유지하면서 차량 중심의 콘텐츠와 탐색 구조를 재구성한 프로젝트입니다. 메인 페이지에서는 주요 모델의 시각적 강조와 콘텐츠 접근성을, 서브 페이지에서는 그리드와 분류 메뉴를 활용한 정보 정리에 중점을 두었습니다. 이를 통해 콘텐츠의 목적에 따라 서로 다른 레이아웃과 UI를 구성하는 경험을 쌓았습니다.

02 / DESIGN POINT

Design Point

01. Layout

세로형 타이포그래피를 활용해 제목에 시선을 집중, 달력과 주문·배송 안내를 순서대로 배치하여 주요 정보를 쉽게 확인할 수 있도록 구성

02. Color & Type

차분한 퍼플과 그레이 계열의 컬러를 활용하여 겨울 특유의 고요한 분위기를 표현, 제목은 격자형 타이포그래피로 구성해 시각적인 차별화

03. Visual

겨울 풍경 이미지를 일러스트 스타일로 가공하여 배경에 활용, 부드러운 색감과 그래픽 요소를 통해 차분하고 감성적인 분위기를 연출
